Drawing Shapes — SwiftBot
A Java program that commands a SwiftBot robot to autonomously draw geometric shapes with precision, using mathematical logic and movement calibration.

What It Does
Input a shape command and the SwiftBot will physically draw it on the ground:
Triangle — 3-sided shape with calculated turning angles
Square — 4-sided shape with 90° turns
Pentagon — 5-sided shape using precise angle computation

How It Works
Uses trigonometry (SOHCAHTOA) to calculate the exact turning angles and movement distances for each shape
Stores shape data using arrays for structured command handling
Wheel speed calibration ensures the robot moves at a constant, consistent rate for drawing accuracy
Includes a safe stop function to cleanly terminate the program after execution

	
Language	Java
Concepts	Trigonometry, Algorithms, Arrays
Hardware	SwiftBot robot

Project Highlights
Developed algorithms from scratch to translate geometry into robot movement
Applied SOHCAHTOA to compute angles and distances without relying on external libraries
Iterative testing and motion calibration to improve drawing accuracy
Strengthened debugging and problem-solving skills through hardware-software integration
